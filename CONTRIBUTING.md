# Contributing to TrailMate

**English** · [Español](CONTRIBUTING.es.md)

Thank you for helping. Issues and pull requests can be written in English or Spanish. TrailMate is an alpha, and reports from other classes, races and level ranges are what it needs most.

## Report a problem

Open an issue with:

1. What you did and what you expected.
2. The output of `/tm test`: in the game, open the panel's **Log** tab, select everything and copy it. It holds no character or account names.
3. A screenshot if it is about the arrow, the map or a window. Please crop out your character's name and chat.

## Change the code

- `TrailMate/core/` is plain Lua 5.1 with no game API, and every change there comes with a test in `spec/`.
- `TrailMate/game/` talks to the game. Check every game function before using it, because this client is new and differs from classic and retail.
- `TrailMate/data/` is generated by the scripts in `tools/`. Change the script, not the data.
- The bridge (`bridge/`) is Go with the standard library only. Please do not add dependencies without opening an issue first.

Before you open a pull request:

```bash
luacheck .
busted
cd bridge && gofmt -l . && go vet ./... && go test ./...
```

The CI runs the same checks, and a pull request is merged only when they pass.

## Fix a translation

The texts are in English in the code; Spanish is in `TrailMate/core/Locale.lua` and every other language in `TrailMate/core/locales/` (`deDE.lua`, `frFR.lua`, `itIT.lua`, `ptBR.lua`, `ruRU.lua`, `koKR.lua`, `zhCN.lua`, `zhTW.lua`). Those were translated with AI, so a native speaker's eye is welcome: change the text on the right, keep the English key on the left as it is, and keep its `%s` and `%d` in the same order (a test checks it). A text missing from a file shows in English.

## Rules the addon keeps

- **It advises, it never plays.** No key presses, movement, buying, selling or spending on the player's behalf.
- **It depends on no other addon** at run time.
- **The AI companion has no tools.** It only answers in text, and what comes back to the game is plain data that the addon checks before using it.
- **No personal data** in code, logs or saved variables beyond what the addon needs.
